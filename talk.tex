% Важную роль в экосистеме risc-v играет проект LLVM. LLVM --- инфраструктура для создания компиляторов. LLVM имеет множество целевых плафторм, в том числе и RISC-V. Спецификация ISA целевой архитектуры описывается в LLVM декларативно, на специальном декларативном языке, который называется TableGen.

% Одноврменно, существует язык Sail, предназначенный для определения моделей процессорных архитектур. На Sail существует оффициальная, одобренная сообществом risc-v foundation модель risc-v isa. Модель представляет из себя поведенческую спецификацию.

% Несмотря на наличие двух независимых спецификаций RISC-V ISA, в настоящее время не существует инструментов, позволяющих систематически сопоставлять эти спецификации и проверять их согласованность. Это создаёт риск накопления расхождений по мере их эволюции.
% Наличие расхождений может приводить к некорректной генерации кода компилятором и снижению общей надёжности экосистемы RISC-V. Поэтому актуальна проблема валидации спецификаций относительно друг друга

\begin{frame}{Введение}
    \begin{itemize}
        \item RISC-V --- открытая, расширяемая ISA (Instruction Set Architecture)

        \item Sail\footnote[frame]{\url{https://github.com/rems-project/sail/}} --- язык для описания моделей процессорных архитектур. Позволяет задать семантику исполнения процессорных инструкций
        \begin{itemize}
            \item sail-riscv\footnote[frame]{\url{https://github.com/riscv/sail-riscv}} --- формальная, поведенческая спецификация RISC-V ISA
        \end{itemize}

        \item LLVM\footnote[frame]{\url{https://llvm.org}} --- инфраструктура для компиляторов
        \begin{itemize}
            \item Спецификация ISA описывается декларативно на TableGen
        \end{itemize}

        \item Актуальна проблема валидации спецификаций относительно друг друга
    \end{itemize}
\end{frame}

\begin{frame}[fragile]{Обзор. TableGen}

\begin{itemize}
    \item TableGen\footnote[frame]{\url{https://llvm.org/docs/TableGen/}} --- декларативный язык, который используется в LLVM для описания предметно-ориентированной информации
    \item В частности, для описания спецификации ISA целевой платформы
    \item Описываются следующие свойства:
    \begin{itemize}
        \item Мнемоники
        \item Коды инструкций
        \item \textbf{Входные}, \textbf{выходные операнды}
        \item \textbf{Читает из памяти}, \textbf{пишет в память}
        \item Коммутативность
        \item ...
    \end{itemize}
    \item Файлы с TableGen кодом имеют расширение \texttt{.td}
    \item При помощи утилиты \texttt{llvm-tblgen} можно скомпилировать в \texttt{JSON}
\end{itemize}

\begin{frame}[fragile]{Обзор. Sail-riscv}


    \begin{itemize}
        \item Sail-riscv\footnote[frame]{\url{https://github.com/riscv/sail-riscv}} --- это модель архитектуры RISC-V
        \item Модель представляет из себя интерпретатор инструкций

        \begin{itemize}
            \item \texttt{AST}, причём один узел может представлять множество инструкций
            \item \texttt{encdec} функций, задающих отображения кода инструкции (opcode) в узлы AST
            \item \texttt{assembly} функций, отображающих узлы AST в строки
            \item \texttt{execute} функций, задающих семантику исполнения инструкций
        \end{itemize}

    \end{itemize}


\begin{lstlisting}[caption={}, language=sail, frame=single]
function clause execute( ADD(rs2, rs1, rd) ) = {
    let rs1_val = X(rs1);                  // read the rs1
    let rs2_val = X(rs2);                  // read the rs2
    let result : xlenbits = rs1_val + rs2_val; // compute
    X(rd) = result;                        // write result to rd
    RETIRE_SUCCESS
}
\end{lstlisting}

\end{frame}

\begin{frame}[fragile]{Реализация. Особенности sail-riscv-p}

        \item Расширение P (Packed SIMD) предназначено для ускорения целочисленных и fixed point вычислений

function clause execute(PEXT_64BITS_ADD_SUB(rs2, rs1, rd, op))
