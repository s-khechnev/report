% Важную роль в экосистеме risc-v играет проект LLVM. LLVM --- инфраструктура для создания компиляторов. LLVM имеет множество целевых плафторм, в том числе и RISC-V. Спецификация ISA целевой архитектуры описывается в LLVM декларативно, на специальном декларативном языке, который называется TableGen.

% Несмотря на наличие двух независимых спецификаций RISC-V ISA, в настоящее время не существует инструментов, позволяющих систематически сопоставлять эти спецификации и проверять их согласованность. Это создаёт риск накопления расхождений по мере их эволюции.

\begin{frame}{Введение}
    \begin{itemize}
        \item RISC-V --- открытая, расширяемая ISA (Instruction Set Architecture)

        \item Sail\footnote[frame]{\url{https://github.com/rems-project/sail/}} --- язык для описания моделей процессорных архитектур. Позволяет задать семантику исполнения процессорных инструкций
              \begin{itemize}
                  \item sail-riscv\footnote[frame]{\url{https://github.com/riscv/sail-riscv}} --- формальная, поведенческая спецификация RISC-V ISA
              \end{itemize}

        \item LLVM\footnote[frame]{\url{https://llvm.org}} --- инфраструктура для компиляторов
              \begin{itemize}
                  \item Спецификация ISA описывается декларативно на TableGen
              \end{itemize}

        \item Актуальна проблема валидации спецификаций относительно друг друга
    \end{itemize}
\end{frame}

\begin{frame}[fragile]{Обзор. Sail-riscv}


    \begin{itemize}
        \item Sail-riscv\footnote[frame]{\url{https://github.com/riscv/sail-riscv}} --- это модель архитектуры RISC-V на Sail
        \item Модель представляет из себя реализацию интерпретатора инструкций RISC-V
              % \item Модель можно скомпилировать в эмулятор на \C{} или \OCaml{}, который интерпретирует \texttt{elf} файлы

              \begin{itemize}
                  \item \texttt{AST}
                  \item \texttt{encdec}, кодирование/декодирование кода инструкции (opcode) в AST
                  \item \texttt{assembly}, отображение AST в мнемоники
                  \item \texttt{execute}, семантика исполнения инструкций
              \end{itemize}

    \end{itemize}


    \begin{lstlisting}[caption={}, language=sail, frame=single]
function clause execute( ADD(rs2, rs1, rd) ) = {
    let rs1_val = X(rs1);                  // read the rs1
    let rs2_val = X(rs2);                  // read the rs2
    let result : xlenbits = rs1_val + rs2_val; // compute
    X(rd) = result;                        // write result to rd
    RETIRE_SUCCESS
}
    \end{lstlisting}

\end{frame}

        \item \textbf{Sail}

                  \item Синтаксический анализ файлов при помощи библиотеки компилятора Sail

                            \item Входные и выходные операнды

              \end{enumerate}

        \item Полученная информация сравнивается, и генерируется отчёт, содержащий расхождения
